# react-native-financial-charts

A high-performance financial visual chart for React Native built with Skia.

## Installation


```sh
npm install react-native-financial-charts
```


## Usage


```js
import { multiply } from 'react-native-financial-charts';

// ...

const result = await multiply(3, 7);
```
