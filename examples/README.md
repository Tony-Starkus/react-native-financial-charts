# Examples For AI Agents

Estes exemplos nao substituem o app `example/`. Eles explicam padroes reais do codigo para ajudar agentes a modificar o projeto com seguranca.

## Lista

- `line-chart-lookup-map.md`: cursor preciso do LineChart.
- `bar-chart-picture-culling.md`: renderizacao batch e culling do BarChart.
- `pie-chart-aggregation.md`: regras de agregacao do PieChart.
- `candlestick-visible-scale.md`: escala dinamica do CandlestickChart.
- `candlestick-utils-test.md`: padrao de teste de utilitarios puros.

## Regra Geral

Antes de criar um exemplo novo, procure primeiro um uso real em:

- `example/src/App.tsx`
- `docs/*ChartDocs.md`
- `src/__tests__`
